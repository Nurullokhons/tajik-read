# Tajik Read — исходный код MVP

Это стартовый проект Flutter для Android с заделом на iOS.

## Уже реализовано в исходниках
- выбор фотографии камерой или из галереи;
- нормализация EXIF-ориентации изображения;
- офлайн OCR через Tesseract с языком `tgk`;
- поле проверки и редактирования распознанного текста;
- разбиение текста на слова;
- экран скорочтения с таймером 60 секунд;
- ручная кнопка «ХОНДАМ» и подсчёт подтверждённых слов;
- экран результата.

## Важно: языковая модель
Файл `tgk.traineddata` — обязательная модель таджикского языка. Она не включена в архив, потому что её нужно отдельно получить из официального репозитория Tesseract.

Официальный файл модели:
https://raw.githubusercontent.com/tesseract-ocr/tessdata_fast/main/tgk.traineddata

Сохраните его в:
`assets/tessdata/tgk.traineddata`

Конфигурация `assets/tessdata_config.json` уже содержит имя `tgk.traineddata`.

## Создание платформенных папок и запуск
Нужны Flutter SDK и Android SDK.

В терминале из папки проекта:
```bash
flutter create --platforms=android,ios .
flutter pub get
flutter run
```

Сборка APK:
```bash
flutter build apk --release
```

APK появится по пути:
`build/app/outputs/flutter-apk/app-release.apk`

## Проверка iOS в будущем
На macOS с Xcode:
```bash
flutter create --platforms=ios .
flutter pub get
flutter build ios
```

## Текущие ограничения MVP
- Автоповорот учитывает EXIF-ориентацию камеры. Геометрическое исправление перспективы и ручной поворот страницы пока не реализованы.
- Таймер стартует сразу при открытии экрана чтения.
- Слово засчитывается только после нажатия кнопки. Слово, оставшееся на экране в момент окончания минуты, не засчитывается.
- Пока нет истории результатов и автоматического режима.
- Перед первым полноценным запуском нужно проверить OCR на фотографиях пользователя и при необходимости настроить параметры Tesseract.

## Онлайн-сборка через GitHub Actions
В архив добавлен workflow `.github/workflows/android-apk.yml`.

1. Создайте на GitHub новый репозиторий `tajik-read`.
2. Загрузите в него все файлы проекта из архива (включая скрытую папку `.github`).
3. Откройте вкладку **Actions** и выберите **Build Tajik Read APK**.
4. Нажмите **Run workflow**. Также сборка запускается автоматически при push в ветку `main`.
5. После успешной сборки откройте запуск workflow, найдите **Artifacts** и скачайте `tajik-read-android-apk`.

Workflow сам создаёт Android/iOS служебные папки, скачивает `tgk.traineddata`, устанавливает зависимости, запускает тесты и собирает APK. Для скачивания результата нужна авторизация в GitHub.


## Tajik Read 0.2 — абзацы, первый этап
- Один перенос строки внутри абзаца объединяется пробелом.
- Пустая строка сохраняется как граница абзаца.
- В скорочтении слова идут непрерывно: границы абзацев не добавляют паузу и не увеличивают счётчик.
- Добавлены тесты переноса строк, абзацев и подсчёта слов.

Ограничение: используется текстовый вывод Tesseract. Если OCR не выдал пустую строку между абзацами, границу не всегда можно восстановить. Следующий этап — получение hOCR/координат строк и анализ отступов и межстрочных интервалов на Android.
